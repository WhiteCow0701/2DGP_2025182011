# Sonic 애니메이션 뷰어 PRD

## 1. 문서 목적

`pico2d`로 Sonic 스프라이트 시트의 모든 애니메이션을 순서대로 재생하는 단일 파일 프로그램을 개발한다.

## 2. 산출물

- 실행 파일: `sonic_animation_viewer.py`
- 스프라이트 이미지: `sonic-sprite.png`
- 외부 설정 파일이나 별도 애니메이션 모듈은 사용하지 않는다.

## 3. 핵심 기능

- 스프라이트 시트에 포함된 모든 동작 애니메이션을 재생한다.
- 각 애니메이션은 5회 반복한다.
- 한 애니메이션이 끝나면 1초 정지한 뒤 다음 애니메이션을 재생한다.
- 마지막 애니메이션까지 재생하면 첫 애니메이션부터 다시 시작한다.
- 전체 재생은 프로그램이 종료될 때까지 무한 반복한다.
- 캐릭터를 기본 `110x110` 크기로 출력한다.

## 4. 자연스러운 애니메이션 기준

- 프레임 전환은 반복문 횟수가 아니라 경과 시간 기준으로 처리한다.
- 기본 프레임 간격은 약 `0.08~0.12초`로 설정하고, 동작별로 조정할 수 있게 한다.
- 프레임 갱신 중에도 화면 렌더링은 계속 수행하여 움직임이 끊기지 않게 한다.
- 5회 반복 후 1초 대기할 때는 마지막 프레임을 유지하고 화면을 깜빡이지 않는다.
- 애니메이션이 바뀌어도 캐릭터의 발 위치와 중심 기준이 크게 흔들리지 않게 정렬한다.
- 모든 프레임은 기본 `110x110` 출력 크기와 기준 좌표를 사용하며, 필요한 경우 애니메이션별 출력 크기만 별도로 지정한다.
- 프레임 이미지가 없는 구간이나 잘못된 영역은 재생하지 않고 사전에 검증한다.

## 5. 기술 요구사항

- Python과 `pico2d`를 사용한다.
- 소스는 `sonic_animation_viewer.py` 한 파일로 작성한다.
- 스프라이트 시트의 프레임 위치, 프레임 수, 재생 순서는 코드에서 명확히 관리한다.
- 각 애니메이션은 프레임 목록, 프레임 간격, 출력 크기를 독립적으로 설정할 수 있다.
- 메인 루프는 `get_time()` 등 시간 정보를 사용해 프레임과 대기 상태를 갱신한다.
- 긴 `delay()` 호출로 입력, 창 갱신, 렌더링을 멈추지 않는다.
- 캔버스 크기는 1200x600으로 한다.

## 6. 사용자 흐름

1. 프로그램이 창과 스프라이트 이미지를 초기화한다.
2. 첫 번째 애니메이션을 5회 재생한다.
3. 1초 대기한다.
4. 다음 애니메이션으로 이동해 같은 과정을 반복한다.
5. 모든 애니메이션을 재생하면 첫 번째 애니메이션으로 돌아간다.

## 7. 완료 조건

- 프로그램 실행 시 오류 없이 화면이 열린다.
- 모든 애니메이션이 누락 없이 지정된 순서로 재생된다.
- 각 애니메이션이 정확히 5회 재생된다.
- 애니메이션 사이에 1초 대기 시간이 적용된다.
- 마지막 애니메이션 이후 처음부터 자동으로 반복된다.
- 캐릭터가 기본 `110x110` 크기로 식별 가능하게 표시된다.
- 프레임 전환이 일정한 시간 간격으로 진행되고 재생 중 끊김이나 불필요한 위치 흔들림이 없다.
- 단계별 개발을 진행하며 최소 20개 이상의 의미 있는 한국어로 된 커밋을 남긴다.
