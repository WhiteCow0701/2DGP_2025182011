# 소년 AutoRun 상태 추가 PRD

## 1. 문서 목적

기존 `IDLE`, `RUN`, `SLEEP` 상태에 키 조작 없이 자동으로 달리는
`AUTORUN` 상태를 추가한다. 상태 전이를 명확히 분리하고, 실행 결과와
상태 다이어그램을 함께 제출할 수 있도록 한다.

## 2. 대상 파일

- `main.py`: 키보드 입력과 게임 루프
- `boy.py`: 소년 객체와 상태 머신
- `autorun.py`: AutoRun 상태 클래스
- `animation_sheet.png`: 캐릭터 애니메이션 스프라이트
- `state_diagram.svg`: 구현 상태 다이어그램

## 3. 기능 요구사항

1. `IDLE` 상태에서 `a` 키를 누르면 `AUTORUN` 상태로 전환한다.
2. `AUTORUN`에서는 방향키를 누르지 않아도 소년이 계속 수평 이동한다.
3. AutoRun 속도는 일반 `RUN`보다 빠르다.
4. AutoRun 중 소년의 출력 크기는 일반 상태보다 크다.
5. 소년이 화면 좌우 경계에 도달하면 진행 방향을 자동으로 반전한다.
6. `AUTORUN` 진입 후 5초가 지나면 `IDLE`로 전환한다.
7. `AUTORUN` 중 방향키를 누르면 자동 이동을 취소하고, 누른 방향의
   기존 `RUN` 상태로 전환한다.
8. 기존 `SLEEP` 상태의 스페이스바 깨우기와 방향키 달리기 동작을 유지한다.
9. 화면 밖으로 나가지 않도록 일반 `RUN`과 `AUTORUN` 모두 위치를 제한한다.
10. 왼쪽과 오른쪽 달리기를 별도 상태로 만들지 않고 `RUN` 하나로 처리한다.

## 4. 입력 및 상태 전이

| 현재 상태 | 입력/조건 | 다음 상태 | 동작 |
|---|---|---|---|
| `IDLE` | `a` 키 | `AUTORUN` | 자동 달리기 시작 |
| `AUTORUN` | 5초 경과 | `IDLE` | 자동 달리기 종료 |
| `AUTORUN` | 왼쪽 방향키 | `RUN` | 왼쪽으로 수동 달리기 |
| `AUTORUN` | 오른쪽 방향키 | `RUN` | 오른쪽으로 수동 달리기 |
| `RUN` | 방향키 해제 | `IDLE` | 수동 달리기 종료 |
| `IDLE` | 5초 경과 | `SLEEP` | 잠들기 |
| `SLEEP` | 스페이스바 | `IDLE` | 깨우기 |
| `SLEEP` | 방향키 | `RUN` | 수동 달리기 시작 |

## 5. 구현 설계

- `AutoRun`을 별도 클래스인 `autorun.py`에 정의한다.
- `AutoRun.update()`가 경과 시간, 자동 이동, 화면 경계 반전,
  5초 종료 여부를 관리한다.
- `AutoRun.draw()`가 확대된 달리기 스프라이트를 출력한다.
- `Boy`는 상태 머신의 전이와 공통 좌표를 관리하고 `AutoRun` 객체에
  AutoRun 상태의 업데이트와 렌더링을 위임한다.
- 시간 기반 업데이트는 `pico2d.get_time()`의 실제 경과 시간을 사용한다.

## 6. 완료 조건

- `a` 키로 `IDLE -> AUTORUN` 전환이 된다.
- AutoRun 중 키 입력 없이도 계속 이동한다.
- 일반 달리기보다 빠르고 캐릭터가 확대되어 보인다.
- 좌우 경계에서 방향이 자동으로 바뀌며 화면 밖으로 나가지 않는다.
- AutoRun 시작 후 5초가 지나면 `IDLE`로 돌아온다.
- AutoRun 중 방향키를 누르면 해당 방향의 `RUN`으로 즉시 전환된다.
- 문법 검사와 상태 전이 테스트를 통과한다.
- `state_diagram.svg`를 소스와 함께 저장소에 포함한다.
